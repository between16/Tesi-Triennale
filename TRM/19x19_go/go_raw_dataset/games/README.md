# CWI professional Go games

Download the `games.tgz` or `games.7z` archive from the
[CWI Database of Go Games](https://homepages.cwi.nl/~aeb/go/games/) and
extract its `games/` contents here. This local source archive is ignored by
Git. Use `extract_9x9.py --board-size 19` to filter valid 19×19 SGFs and
duplicates into `../19x19_professional_games/`; see
[`../../../../docs/DATASETS.md`](../../../../docs/DATASETS.md) for the full
preparation procedure and the source snapshot fingerprint.
